\section{Safety, ethics and reproducibility}\label{sec:ethics}
\paragraph{Static analysis only}
We read samples as data for static analysis. The training container mounts the corpus read-only and runs
with networking disabled. Raw sources, ICFG code fragments, pickles, caches and
weights remain outside Git. The public evidence contains hashes, paths, source labels, numeric statistics and
predictions. PHP-Construct-22 is original benign code with an explicit CC0 manifest.

\paragraph{Licenses and distribution}
The source lock and data card record upstream licences where available. The fetched source retains its
upstream notices. Any sample archive prepared for grading is private and includes a SHA-256 checksum.

\paragraph{Evidence and reproduction}
\texttt{scripts/reproduce.sh} builds isolated v2 inputs, verifies source bytes, prepares graphs/splits, trains the
planned configurations and validates the resulting inventory. \texttt{src/run\_metadata.py} checks CUDA and records
runtime/package/extension versions, image ID and source hashes. Seeds and the actual retained predictions are
provided; parallel Gensim training and CUDA scatter operations can still vary numerically.
The runtime coordinator overlaps independent groups and keeps shared embedding-cache writes in one group.
No model settings or seeds are reduced to fit resources.

The published snapshot under \texttt{evaluation/v2/} has \result{checked_runs} checked runs and
\result{checked_splits} splits. \texttt{src/check\_evaluation.py} verifies exact configurations, test IDs, labels,
full-precision probabilities, confusion counts and metrics, then seals the evidence with SHA-256. Its
\texttt{--verify-seal} mode needs only standard-library Python. The historical v1 seal remains separate.
\texttt{report/render\_metrics.py} checks the v2 seal before generating manuscript numbers and tables.
\texttt{scripts/build\_report.sh} runs LaTeX/BibTeX and checks rendered text bounds, references, caption order and
main-report column balance; visual inspection complements these checks.

Saved-prediction analysis and report rendering require no GPU or raw malware. Rebuilding extraction statistics
and the corpus requires the pinned raw sources. The measured parsing/model times describe this bounded runtime;
we make no industrial-server throughput or deployment-effectiveness claim.
