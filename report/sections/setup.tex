\section{Experimental setup}\label{sec:setup}
\paragraph{Hardware and software}
The v2 evaluation uses a Tesla V100-SXM2 (16\,GB), Python~3.11.18, PHP~8.2.35,
PyTorch~2.4.1+cu121 (CUDA~12.1), PyTorch Geometric~2.6.1 and Gensim~4.3.3.
The container is limited to at most 48 CPU cores and 10\,GB host RAM, with four extraction workers.
Independent runs share these resources. A CUDA computation and the regression tests passed in that image
before evaluation.
The Docker image ID, full package/extension lists and hashes of the evaluated source files are retained
in \texttt{evaluation/v2/environment.json}. Historical v1 predictions, produced with PHP~8.3 and a laptop GPU,
are preserved separately and do not supply the v2 results.

\paragraph{Metrics}
Files labelled as webshells by source form the positive class. We report precision, recall, true-negative rate
(TNR), accuracy, F1 and the false-positive rate (FPR), which equals $1-\mathrm{TNR}$. We report means and
95\% Student-$t$ intervals across five seeds for the main comparisons and three seeds for the sweeps.
The analysis JSON also records 95\% Wilson intervals for the \xs{} test counts at seed~0.

\paragraph{Experiments}
\begin{enumerate}
  \item \textbf{Table 2 replication}: 6 embeddings $\times$ 5 seeds, 2-layer GCN, hidden 10, batch 10 (\pr).
  \item \textbf{Fig.~8 replication}: ablation \emph{none} (raw statements, no risk), \emph{n} (normalised),
        \emph{n+w} (normalised + risk), FastText + GCN (\pr) and FastText + GAT (\cg).
  \item \textbf{Fig.~6/7 replication}: embedding dimension 20--120 and context window 2--7 (FastText + GCN, 3 seeds).
  \item \textbf{Table 4 replication}: GCN/GIN/GAT with the Table~3 optimum, FastText (\pr).
  \item \textbf{Beyond the paper}: GCN and GAT on \cg{} and \xs; baselines on all protocols.
\end{enumerate}

\paragraph{Baselines}
We evaluate the baselines on the same splits (\texttt{src/baselines.py}). The text baselines fit logistic
regression (LR) or XGBoost on TF-IDF features from regular-expression tokenisation of the first 100,000
bytes of each file. We hash unigrams and bigrams into $2^{18}$ features and select the 5,000 highest-scoring
features by $\chi^2$ for XGBoost. The rule baselines flag a critical call, any risky call, or a risky call
combined with a request-input indicator. A separate XGBoost baseline uses 12 graph features, including
size, risk counts, input indicators and parser flags.

\paragraph{Selection and inference}
The GNN checkpoint maximises validation F1 with early stopping; the classification threshold is fixed at 0.5.
All embedding models, TF-IDF weights and feature selection are fitted on training files only.
Cross-source experiments reuse the corresponding clean training/validation sets and training embedding.
Reported confidence intervals describe variation over these five coupled split/initialisation seeds, not
uncertainty over future projects. Wilson intervals are descriptive file-level intervals; correlated variants
can violate their independence assumption. Paired tests are exploratory and unadjusted for multiple comparisons.
A non-significant result does not establish equivalence. Alarm-budget thresholds are selected on the test ROC
and are explicitly optimistic oracle bounds, not validation-calibrated deployment operating points.
