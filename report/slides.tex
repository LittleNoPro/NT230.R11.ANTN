\begin{frame}{What are we trying to detect?}
\begin{block}{Observation and decision}
A PHP source file appears or changes on a web server. A static detector assigns a file-level score before execution.
\end{block}
\begin{itemize}
\item Webshell capabilities include command execution, file management and encoded loaders.
\item Legitimate administration, callbacks and upload features can look similar.
\item Source alone does not establish authorization or intent.
\end{itemize}
\medskip
\textbf{Questions:} Can we reconstruct the reported method? Which components help? How much do duplicates and source style matter?
\vfill
\footnotesize Based on Feng et al., \emph{Computer Networks} 245 (2024), 110406.
\end{frame}

\begin{frame}{What the study does and does not establish}
\begin{itemize}
\item Graph collisions expose information loss in this implementation, not unknown authors' code.
\item Few projects, correlated public variants and uncertain source labels limit generalisation.
\item The 150-file human audit still has 300 unfilled decisions; no agreement/error rate is invented.
\item No industrial-server deployment, dynamic taint proof or general deobfuscation result.
\end{itemize}
\begin{block}{Static handling}
Samples are read/parsed, never executed or served. Raw sources and graph code fragments remain outside Git.
\end{block}
\end{frame}

\begin{frame}{Reproducible evidence and next steps}
\begin{itemize}
\item Safe snapshot: \texttt{evaluation/v2/}; full configurations and per-file predictions.
\item Standard-library seal verification; generated report values; 13 regression tests.
\item Private trained demo and complete pinned sources are available locally and on the GPU VPS.
\end{itemize}
\begin{block}{Takeaway}
Corpus-level F1 measures source-label separation. Representation limits and source-shift tests determine how
far that result can be interpreted.
\end{block}
Next: independent labels, broader legitimate code, calibrated thresholds and new-project evaluation.
